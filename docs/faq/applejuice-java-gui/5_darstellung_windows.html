5. JavaGUI wird unter Windows fehlerhaft gezeichnet

Die Oberfläche flackert, bleibt teilweise leer oder wird verzerrt dargestellt. Abhilfe: Direct3D für Java abschalten.

  1. Beende das JavaGUI vollständig.
  2. Öffne den Installationsordner, normalerweise C:\Program Files\appleJuiceNETZ\JavaGUI.
  3. Sichere app\appleJuice JavaGUI.cfg und öffne die Datei mit einem Texteditor, bei Bedarf als Administrator.
  4. Ergänze unter [JavaOptions] diese beiden Zeilen. Lass alle anderen Zeilen unverändert: 
    java-options=-Dsun.java2d.d3d=false
java-options=-Dsun.java2d.noddraw=true
  5. Speichere die Datei und starte das JavaGUI erneut.

Beispiel für den Abschnitt: 

[JavaOptions]
java-options=-Djpackage.app-version=0.86.5
java-options=--enable-native-access=ALL-UNNAMED
java-options=-Dsun.java2d.d3d=false
java-options=-Dsun.java2d.noddraw=true
Updates können die Datei überschreiben; prüfe die Einstellung danach erneut.
