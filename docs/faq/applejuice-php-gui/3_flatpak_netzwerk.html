3. Flatpak im Netzwerk erreichbar machen

Die phpGUI als Flatpak lauscht standardmäßig nur auf 127.0.0.1:8088. Mit PHPGUI_BIND=0.0.0.0 ist sie auch im Netzwerk erreichbar. 

flatpak override --user \
    --env=PHPGUI_BIND=0.0.0.0 \
    --env=CORE_HOST=http://192.168.2.1 \
    --env=CORE_PORT=9851 \
    io.github.applejuicenetz.phpgui

Zurücksetzen: flatpak override --user --unset-env=PHPGUI_BIND io.github.applejuicenetz.phpgui
Läuft die phpGUI schon, vorher über das Tray-Symbol beenden.
