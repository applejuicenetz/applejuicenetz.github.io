2.18. error creating file / error while writing

  • Meldung:
    • error creating file …
    • error while writing …
  • Problem: Die Datei im Temp-Ordner kann nicht angelegt oder beschrieben werden, der Download kommt nicht voran
  • mögliche Ursachen:
    • Festplatte voll
    • fehlende Schreibrechte im Temp-Ordner
    • defekter Datenträger
  • Lösung: Schaffe freien Speicherplatz, korrigiere die Berechtigungen oder verschiebe den Temp-Ordner auf einen anderen Datenträger
