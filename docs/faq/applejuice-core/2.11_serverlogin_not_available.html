2.11. serverlogin not available

  • Meldung: serverlogin not available
  • Ursache: Die Ursache steht immer über dieser Fehlermeldung, zum Beispiel:
Serverversion is too old. Der Server ist für deinen Core zu alt.
Version was blocked. Der Server hat deine Core-Version gesperrt. Aktualisiere den Core.
server is full. Der Server ist voll. Der Core versucht einen anderen Server.
unkown error (N) while serverlogin Unbekannter Fehlercode N beim Login.
