19. Der Core ist abgestürzt, wo finde ich die hs_err_pid Datei?

Stürzt die Java Laufzeit (JVM) selbst ab, schreibt sie eine Fehlerdatei mit dem Namen hs_err_pid<PID>.log. <PID> ist die Prozess-ID des abgestürzten Core. Diese Datei hilft bei der Fehlersuche und sollte jedem Fehlerbericht angehängt werden.

Windows C:\Benutzer\%USERNAME%\appleJuice\
Linux ~/appleJuice/ bzw. /home/$USER/appleJuice/
macOS ~/appleJuice/ bzw. /Users/$USER/appleJuice/
Docker im Container Volume /config/ im Unterordner appleJuice/
Windows (Portable) im Ordner appleJuice\ neben den Ordnern Core und GUI
Die Datei kann sensible Daten wie Pfade, Benutzernamen und Umgebungsvariablen enthalten. Sie liegt im selben Ordner wie die Konfiguration (siehe Punkt 15). Prüfe sie vor dem Veröffentlichen und entferne persönliche Angaben.
