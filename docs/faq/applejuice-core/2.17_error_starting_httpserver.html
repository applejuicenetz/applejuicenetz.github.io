2.17. error starting httpserver

  • Meldung: error starting httpserver: …
  • Problem: Die GUI kann sich nicht mit dem Core verbinden
  • Ursache: Der konfigurierte XML-Port des Cores ist bereits in Verwendung
  • Lösung:
    • prüfe, ob der Core bereits läuft
    • wähle einen anderen XML-Port (settings.xml, siehe Punkt 11)
Für den TCP-Port gilt 2.2.
