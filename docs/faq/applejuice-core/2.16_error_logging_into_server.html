2.16. error logging into server

  • Meldung: error logging into server: … (Stage)
  • Problem: Der Login bei diesem Server ist fehlgeschlagen
  • Ursache: Die Verbindung zum Server wurde während des Logins unterbrochen. Der Text in Klammern nennt den Schritt, bei dem es passiert ist.
  • Lösung: Meist keine nötig. Erscheint danach logged in, ist der Core mit einem Server verbunden.
