2.20. error while replacing … .xml

  • Meldung: error while replacing settings.xml, the new settings stay in settings.xml.new (ebenso für shareinfo.xml, server.xml und shareidx.xml)
  • Problem: Änderungen konnten nicht in die eigentliche Datei gespeichert werden, sie liegen in der Datei mit der Endung .new
  • mögliche Ursache: fehlende Schreibrechte im Konfigurationsordner, siehe Punkt 11
  • Lösung: Der Benutzer, unter dem der Core läuft, braucht Schreibrechte für den Konfigurationsordner. Korrigiere sie und starte den Core neu.
