2. Wann brauche ich fixajfsp?

Wenn Links nicht von selbst mit deiner GUI öffnen. Das ist der Fall bei:

  • der Portable-Version, weil sie kein Setup durchläuft
  • einer verschobenen Portable-Version, dann einfach erneut starten und den neuen Pfad wählen
  • einer GUI, die ohne Setup installiert wurde
Nach dem Windows Setup brauchst du fixajfsp nicht. fixajfsp läuft nur unter Windows und braucht Administratorrechte.
