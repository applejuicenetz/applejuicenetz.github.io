3.4 Glossar

Begriff Bedeutung
Routing table / Hashtable Aufteilung des Hash-Raums auf die zuständigen Server. Die angezeigte Zeit ist der Erstellungszeitpunkt der Tabelle.
I-Time Erstellungszeitpunkt der Whitelist eines Servers. Sie legt erlaubte Core-Builds und das Mindestprotokoll fest.
Last seen Zeit seit dem letzten Lebenszeichen. Als aktiv gelten Server mit einem Lebenszeichen innerhalb der letzten fünf Minuten.
Refs Einträge im Dateiindex, die auf diesen Server verweisen. Referenzierte Server werden nicht aus der Liste entfernt.
Rep Erreichbarkeitsbewertung: Eine erfolgreiche Verbindung bringt 20 Punkte (höchstens 10 insgesamt), ein Fehlversuch kostet 50. Server mit negativer Bewertung erhalten keinen Hash-Bereich.
Queue Protokollbefehle, die auf die nächste Verbindung zu diesem Server warten.
Tasks Anzahl der Go-Goroutines im Systembereich. Der Klammerwert zieht offene Verbindungen ab und ist nur ein grober Anhaltspunkt, keine genaue Aufschlüsselung.
Hash share Anteil am Hash-Raum, nicht Anteil an Dateien oder Traffic.
