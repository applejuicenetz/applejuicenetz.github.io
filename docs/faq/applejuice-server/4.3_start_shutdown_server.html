4.3 Der Server beendet sich gleich nach dem Start

Starte den Server im Terminal und lies die Fehlermeldung. Prüfe insbesondere:

  • Belegter Port: port, port + 1 und webport müssen frei sein. Prüfe, ob bereits eine Instanz läuft.
  • Bind-Adresse: bindip muss zu einer lokalen Netzwerkschnittstelle passen oder 0.0.0.0 sein.
  • Konfiguration: Prüfe die JSON-Syntax und die in der Fehlermeldung genannten Werte in server.json.
  • Datenordner: Mit -data /pfad/zum/datenordner kannst du den gewünschten Ordner ausdrücklich auswählen. Der Server benötigt dort passende Datei- und Verzeichnisrechte.

Eine vorhandene server.xml wird nur dann importiert, wenn noch keine server.json existiert. Änderungen an der XML-Datei wirken danach nicht mehr.

Der Zeitabgleich verwendet NTP. Der Zeitserver wird über timeserver konfiguriert; der alte Java-Parameter --usemyNTP gilt nicht für den Go-Server.
