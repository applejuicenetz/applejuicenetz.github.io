4.7 Ich sehe in der Web-Oberfläche nur meinen Server

Dem Server fehlen bekannte andere Server. Prüfe im Log, ob der Abruf der öffentlichen Serverliste fehlgeschlagen ist oder über APPLEJUICE_SERVERLIST_URL abgeschaltet wurde.

Du kannst in der Web-Oberfläche unter Servers einen Server aus der Serverliste mit Host und Core-Port hinzufügen. Für die Verbindung zwischen Servern wird automatisch der nächste Port verwendet.

Kommt weiterhin kein Kontakt zustande, prüfe DNS-Auflösung, Firewall und Erreichbarkeit beider Server-Ports. Einzelne graue Verbindungspunkte sind kein Beleg für Isolation; siehe Punkt 3.3.
