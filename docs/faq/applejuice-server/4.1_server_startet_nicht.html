4.1 Beim Serverstart öffnet sich kein Fenster

Unter Linux und macOS gibt es kein natives Logfenster. Öffne die Web-Oberfläche im Browser, um Status und Log zu sehen.

Unter Windows öffnet sich bei aktiviertem Tray ein Logfenster. Über Show console im Tray-Menü kannst du es wieder einblenden. Das Schließen-Kreuz blendet es nur aus; Exit im Tray beendet den Server.

Mit -notray oder AJ_NOTRAY=1 läuft der Server ohne Tray und natives Logfenster. Starte ihn zur Fehlersuche im Terminal und prüfe die dortigen Ausgaben. Die Web-Oberfläche bleibt verfügbar, sobald der Server erfolgreich gestartet ist.
