3.2 Welche Ports braucht der Server?

Der Server nutzt drei TCP-Ports. In der server.json werden zwei davon festgelegt:

  • port: Verbindung der Cores zum Server, beispielsweise 9855.
  • port + 1: Verbindung zwischen Servern, im Beispiel 9856. Dieser Port wird automatisch abgeleitet.
  • webport: Web-Oberfläche, beispielsweise 8001.

Die beiden Server-Ports müssen für andere Cores bzw. Server über Router und Firewall erreichbar sein.

Die Web-Oberfläche erreichst du bei lokalem Betrieb mit webport 8001 unter http://127.0.0.1:8001/, sofern die Bind-Adresse dies zulässt.

Gib den Web-Port nur für benötigte Zugriffe frei. Für Zugriffe über das Internet sollte ein HTTPS-Reverse-Proxy vorgeschaltet werden; der Server selbst verwendet HTTP.
