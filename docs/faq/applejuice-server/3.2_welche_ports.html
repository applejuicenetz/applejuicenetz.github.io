3.2 Welche Ports braucht der Server?

Der Server nutzt insgesamt drei Ports – zwei für den Serverbetrieb und einen für den Serverwatcher. Alle drei können durch Ändern der server.xml frei gewählt werden.

<port value="EIN PORT"/> ist der erste TCP-Port. Der zweite Port wird durch „erster Port + 1“ errechnet, z. B. <port value="9855"/> für die Ports 9855 und 9856. Beide TCP-Ports müssen freigegeben werden (Router/Firewall). Der erste Port ist für die Client-Server-Kommunikation, der zweite für die Server-Server-Kommunikation zuständig.

<webport>8001</webport> - ist der Port für den Serverwatcher, der in dem Fall mit http://127.0.0.1:8001 aufgerufen werden kann (Server läuft hier lokal auf dem Rechner). Der Port muss nur freigegeben werden, wenn von außen auf den Serverwatcher zugegriffen werden soll.
