3.6 Wie kann ich noch Informationen vom Server abrufen?

Zusätzlich zur Web-Oberfläche stellt der Server folgende HTTP-Endpunkte am webport bereit:

  • /info.json: Serverstatus als JSON
  • /serverlist.json: bekannte Server als JSON
  • /metrics: Messwerte für Prometheus
  • /log: letzte Logzeilen als JSON
  • /healthz: Health-Check ohne Anmeldung

Bis auf /healthz benötigen diese Endpunkte HTTP Basic Auth mit webuser und webpw aus der server.json. Beispiel bei lokalem Betrieb: http://127.0.0.1:8001/info.json.

/info.xml gibt es ab 0.95.x nicht mehr. Verwende die JSON-Endpunkte statt HTML-Dateien der Web-Oberfläche auszulesen.
