4.5 Verbindungslimits vom Betriebssystem

Jede offene Netzwerkverbindung benötigt einen Dateideskriptor. Das verfügbare Limit hängt von Betriebssystem und Startumgebung ab; es beträgt nicht überall 1024.

Unter Linux zeigt ulimit -n das Limit der aktuellen Shell. Eine Erhöhung gilt für anschließend aus dieser Shell gestartete Prozesse und darf das harte Limit nicht überschreiten.

Bei einem systemd-Dienst ist LimitNOFILE maßgeblich, bei Docker die Einstellung --ulimit nofile=... bzw. ulimits in Compose. Prüfe die Grenzen der tatsächlichen Startumgebung statt nur die einer separaten Login-Shell.
