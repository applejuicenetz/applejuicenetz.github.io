3.5 Wie kann ich die Meldungen mitloggen?

Die Web-Oberfläche zeigt die letzten 1.000 Logzeilen. Unter Windows gibt es bei aktiviertem Tray zusätzlich ein Logfenster.

Für eine dauerhafte Datei kannst du den Server unter Linux oder macOS im Terminal starten und die Ausgaben umleiten:

./ajserver -notray >> aj.txt 2>&1

Die Datei aj.txt wird im aktuellen Arbeitsverzeichnis angelegt bzw. ergänzt. Mit -notray ist dieses Verzeichnis auch der Standard-Datenordner; mit -data /pfad/zum/datenordner kannst du ihn ausdrücklich festlegen.

Bei Docker findest du die Ausgaben über docker logs <Containername>.
