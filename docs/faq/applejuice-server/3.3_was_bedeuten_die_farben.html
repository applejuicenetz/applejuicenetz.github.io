3.3 Was bedeuten die Farben in der Web-Oberfläche?

Anzeige Bedeutung
Grüner Punkt Zu diesem Server besteht gerade eine offene TCP-Verbindung.
Grauer Punkt Gerade keine offene TCP-Verbindung. Das bedeutet nicht, dass der Server offline ist.
Farben im Routing-Balken Jede Farbe kennzeichnet einen Server und dessen Anteil am Hash-Raum. Dieselbe Farbe erscheint in Serverliste und Legende.
Schraffierter Routing-Anteil Der zugehörige Server gilt momentan als inaktiv.

Verbindungen zwischen Servern sind meist kurz. Viele graue Punkte sind deshalb normal. Die Routing-Anteile beschreiben Hash-Bereiche, nicht Dateimengen oder Traffic.
