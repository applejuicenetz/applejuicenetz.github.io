4.4 Der Server benötigt zu viel Speicher oder wird beendet

Prüfe das Serverlog und die Meldungen des Betriebssystems bzw. Containers auf Speichermangel. Beachte auch gesetzte Speicherlimits für den Dienst oder Container.

Die Web-Oberfläche zeigt unter Memory used den belegten Go-Heap und unter Memory system den von der Go-Laufzeit angeforderten Speicher einschließlich Reserven. Letzteres ist nicht der tatsächliche physische Speicherverbrauch des Prozesses.

Der Go-Server kennt keinen Java-Parameter -Xmx. GOMEMLIMIT ist ein weiches Speicherziel der Go-Laufzeit, keine feste Obergrenze für den gesamten Prozess.
