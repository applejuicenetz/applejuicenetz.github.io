2. Wann brauche ich catch_ajfsp?

Wenn du Links aus dem Browser an einen Core schicken willst, ohne eine GUI zu starten, zum Beispiel bei einem Core auf einem Server oder im Heimnetz. Hast du sowieso eine GUI offen, brauchst du es nicht, dafür reicht fixajfsp.

catch_ajfsp läuft nur unter Windows, ist nicht Teil des Windows Setups und braucht keine Administratorrechte. Die Verbindung zum Core ist unverschlüsselt (HTTP), nutze es nur in einem vertrauenswürdigen Netz oder über einen SSH-Tunnel.
