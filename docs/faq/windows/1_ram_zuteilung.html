1. Wie teile ich dem Core mehr RAM zu?

1.1 Ab Core 0.35.185.01

Standardmäßig begrenzt den Java-Heap auf etwa 50 % des von Java erkannten gesamten RAMs mittels -XX:MaxRAMPercentage=50. Manuelle Anpassung:

  1. Beende den Core vollständig und öffne den Installationsordner, normalerweise C:\Program Files\appleJuiceNETZ\Core.
  2. Sichere app\appleJuice Core.cfg und öffne die Datei mit einem Texteditor, bei Bedarf als Administrator.
  3. Ersetze unter [JavaOptions] die Zeile java-options=-XX:MaxRAMPercentage=50 durch java-options=-Xmx2048m für maximal 2 GB Java-Heap. Lass alle anderen Zeilen unverändert.
  4. Speichere die Datei und starte den Core erneut.

Lass genug RAM für Windows und andere Anwendungen frei. Für die Automatik stelle die ursprüngliche Zeile wieder her. Updates können die Datei überschreiben; prüfe deine Einstellung danach erneut.

1.2 Bis Core einschließlich 0.34.101.42

Das alte Setup teilt dem Core automatisch 50 % des aktuell freien RAMs zu. Manuelle Anpassung:

  1. Beende den Core und öffne den Installationsordner, normalerweise C:\Programme\appleJuiceNETZ\Core.
  2. Öffne ajcore.l4j.ini bzw. ajcore_nogui.l4j.ini mit einem Texteditor.
  3. Entferne das # nur vor der -Xmx-Zeile und setze beispielsweise -Xmx2048m für 2 GB.
  4. Speichere die Datei und starte den Core erneut.
