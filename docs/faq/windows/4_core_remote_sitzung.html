4. Core beendet sich bei Remotedesktop

Ab Core 0.35.185.01 kann sich der Core beenden, wenn eine Windows-Sitzung per Remotedesktop von einem anderen Rechner übernommen wird. Die Option -Djava.awt.headless=true verhindert das. Der Core läuft dann ohne Fenster und Tray-Symbol.

  1. Beende den Core und öffne app\appleJuice Core.cfg im Installationsordner mit einem Texteditor, bei Bedarf als Administrator.
  2. Füge unter [JavaOptions] die Zeile java-options=-Djava.awt.headless=true hinzu.
  3. Speichere die Datei und starte den Core erneut.
Siehe auch Punkt 1.1. Updates können die Datei überschreiben.
