17. Wofür ist die Share-Priorität gedacht?

Mit der Share-Priorität machst du eine eigene Datei für andere attraktiver, sodass sie mit einem niedrigeren Powerdownload-Wert schneller an die Datei kommen. Sie ist hauptsächlich für Releaser interessant. Hochgeladen werden deine Dateien auch ohne Priorität.

  • Einstellen: Unter Mein Share die Datei auswählen und setze Priorität wählen.
  • Limit: Du hast insgesamt 1000 Prio-Punkte. Eine einzelne Datei darf höchstens 250 davon bekommen.
  • Credits: Für eine Erhöhung gibt es keinen zusätzlichen 10-%-Creditanteil.
  • Richtwert beim Releasen: Schau, wie viel Powerdownload für deinen Share geboten wird, und addiere etwa 30–50 Punkte. Die maximale Priorität ist meist nicht nötig.
Die Priorität beeinflusst das Credit-System. Setze sie sparsam und nur für Dateien, die du veröffentlichen willst. Eine sehr hohe Priorität kann das Release anderer User behindern. Umgekehrt können andere User dir eine Datei unattraktiv machen, wenn sie ihre Priorität sehr hoch setzen.
