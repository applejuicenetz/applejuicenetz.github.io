1.2. Keine Credits trotz Upload (weitere Ursachen)

Der Core vergibt Upload-Credits nur für Peers mit öffentlicher IP. Sieht der Core als Absender eine private Adresse, werden keine Credits gutgeschrieben, auch wenn der Upload läuft.

Mögliche Ursachen:

  • Etwas zwischen Internet und Core ersetzt die IP des Peers, z. B. NAT oder ein Proxy im Router, in der VM oder im Cluster (bei Kubernetes siehe Punkt 1.3)
  • Rootless Docker oder Podman: der Core sieht dort immer eine interne IP
  • Der Host hat ein VPN oder ein Netz mit sehr großem Subnetz, der Core hält Peers dann für lokal
  • Der Peer sitzt im eigenen LAN, Uploads ins LAN geben nie Credits
