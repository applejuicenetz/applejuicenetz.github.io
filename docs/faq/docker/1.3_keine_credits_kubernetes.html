1.3. Keine Credits trotz Upload (Kubernetes / k3s)

kube-proxy ersetzt die Quell-IP der Peers durch eine interne IP, der Core vergibt dann keine Credits. Lösung: im Service externalTrafficPolicy: Local setzen. 

apiVersion: v1
kind: Service
metadata:
  name: applejuice-core
spec:
  type: LoadBalancer
  externalTrafficPolicy: Local
  selector:
    app: applejuice-core
  ports:
    - name: p2p
      port: 9850
      targetPort: p2p
      protocol: TCP
