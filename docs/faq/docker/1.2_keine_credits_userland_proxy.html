1.2. Keine Credits trotz Upload (Docker Userland Proxy)

Der docker-proxy ersetzt die Quell-IP der Peers durch die Bridge-IP, der Core vergibt dann keine Credits. Lösung: den Userland Proxy abschalten.

  1. In /etc/docker/daemon.json eintragen: {"userland-proxy": false}
  2. Docker neu starten: sudo systemctl restart docker
  3. Container neu erstellen
