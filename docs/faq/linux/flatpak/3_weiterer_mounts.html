2.3. Weitere Ordner im Core-Flatpak erlauben

Standardmäßig hat das appleJuice Core Flatpak nur Zugriff auf:

  • ~/appleJuice/

Alle anderen Ordner, auch Laufwerke unter /media, /mnt oder /run/media, müssen für den Core freigegeben werden. Das geht mit dem folgenden Befehl:

flatpak override --user --filesystem=/path/to/folder io.github.applejuicenetz.core
