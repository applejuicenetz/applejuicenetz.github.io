Der appleJuice Server vermittelt Anfragen zwischen den Cores im appleJuice Netzwerk und prüft, welche Core-Versionen sich verbinden dürfen.

Die Serversoftware steht nur einem kleinen Personenkreis zur Verfügung, um die Stabilität des Netzwerkes zu gewährleisten.
